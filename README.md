# 🌏 AI Translator

**AI Translator** is a real-time speech-to-text translation app that allows users to **speak in English** and get instant translations into a selected target language. The app is fully frontend-based, responsive, and visually appealing.

---

## 🚀 Live Site

🔗 Visit here → **[https://github.com/VHrishita/ai-translator](https://ai-translator-two.vercel.app/)**

---

## Features

- 🎙 Real-time English speech transcription  
- 🌐 Instant translation into multiple languages:
  - Spanish
  - French
  - German
  - Hindi
  - Chinese
  - Korean
  - Japanese
  - Italian
  - Russian
  - Arabic
- ✨ Automatic translation update when target language is changed  
- 🖌 Colorful, modern, and responsive user interface  
- 🔴 Glow effect on recording for live feedback  

---

## Tech Stack

- **Frontend:** React.js  
- **Translation API:** [MyMemory API] 
- **Styling:** CSS3  

---

## How it works

1. The user holds the "🎙 Hold to Talk" button and speaks in **English**.  
2. The app transcribes speech in real-time.  
3. Transcription is instantly translated to the selected language using MyMemory API.  
4. Changing the target language automatically re-translates the current transcription.
